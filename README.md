# Vibe-Code-project
A project about a story line of different outcomes.

## Run the story

Use Python to run the interactive story script:

```bash
python3 story.py
```

## View the story in a browser

Open `index.html` in your browser to play the same story as a web page.

The browser version uses `script.js` and `style.css` to render the story text, choices, and scene backgrounds.
